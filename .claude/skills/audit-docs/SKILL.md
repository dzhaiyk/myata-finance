Проверь и выдай отчёт (только факты, без правок):
1. BR со статусом CONFIRMED, у которых нет ссылки из кода (grep по id) или теста.
2. Валидации, расчёты, переходы статусов и проверки ролей в коде, у которых нет BR.
3. Документы в docs/, которых нет в docs/INDEX.md, и строки INDEX.md без файла.
4. Документы с `updated` старше 90 дней при наличии свежих коммитов в коде их домена.
5. Правила со статусом INFERRED / ASSUMED старше 30 дней.
6. Документы длиннее 300 строк; CLAUDE.md длиннее 150.
Формат: таблица «проблема → файл → предлагаемое действие», не больше 40 строк.
