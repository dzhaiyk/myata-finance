# Скрипты аудита 2022–2025

Входные файлы лежат в `docs/Accounting` основного чекаута (пути захардкожены в скриптах). Все скрипты пишут JSON в текущий каталог и печатают сверочные таблицы. Порядок запуска:

| Шаг | Скрипт | Вход | Выход |
|---|---|---|---|
| 1 | `pnl_excel_parse.py` | `1. ОПиУ и ДДС/1. PnL.xlsx` | `pnl_excel.json` — строки годового P&L по месяцам |
| 2 | `pnl_daily_parse.py` | `PnL daily/PnL_Daily_*.xlsx` | `pnl_daily.json` — наличные расходы из кассы по категориям |
| 3 | `zatratki_parse.py` | `Затратки/<год>/*.xlsx` | `zatratki_monthly.json` — кассовые книги по дням: каналы выручки, затраты, остатки, дрейф |
| 4 | `hist_categorize.py` | `stmt_2022_2025.jsonl` (выписки, разобранные `import_stmt.mjs` по правилам `src/lib/categorize.js`) | `hist_bank.json`, `hist_rows.jsonl` — категории и переводы учредителям |
| 5 | `recon.py` | результаты шагов 1–4 | таблицы «Excel против наличка + банк» и выручка по месяцам |
| 6 | `fot_hist.py` | `ФОТ/2022…2025` | `fot_hist.json` — ведомости по половинам месяца против Excel-ФОТ |
| 7 | `fot_parse2.py --all` | `ФОТ/2026` | ведомости 2026 по отделам (для внесения в `pnl_data`) |
| 8 | `pnl_reimport.py` | `pnl_excel.json` | `sql/reimport_hist.sql` — переимпорт исторического P&L (выполнять только после подтверждения) |

`stmt_2022_2025.jsonl` создаётся `import_stmt.mjs` (см. историю сессии аудита); при потере — пересобрать из выписок теми же правилами, что и импорт в приложении.

Отчёт по результатам: `docs/Аудит-финансов-2022-2025.md`.
