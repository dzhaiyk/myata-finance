# Права

Права назначаются ролям в таблице `permissions` через страницу «Роли»; Админ имеет всё. Ниже — какой ключ проверяет код. ✔ у роли — только там, где это задано кодом или миграцией; остальное «по настройке».

| Действие | Ключ | Админ | Учредитель | Управляющий | Менеджер | Бухгалтер |
|---|---|---|---|---|---|---|
| Открыть страницу «Отчёт дня» | `daily_report.view` (меню) | ✔ | по настройке | по настройке | по настройке | по настройке |
| Создать / сохранить / отправить отчёт | не проверяется (любой с доступом к странице) | ✔ | ✔ | ✔ | ✔ | ✔ |
| Вернуть в черновик, удалить | `daily_report.edit` | ✔ | по настройке | по настройке | по настройке | по настройке |
| Загрузить выписку в отчёте | `bank_import.upload` | ✔ | по настройке | по настройке | по настройке (решение 04.09.2026: дать менеджерам) | по настройке |
| Заполнить из iiko | не проверяется | ✔ | ✔ | ✔ | ✔ | ✔ |

## Исключения
- Ключ `daily_report.create` объявлен, но не проверяется (BR-ACS-004).
- Маршрут `/daily-report` не защищён правом — только меню (BR-ACS-004).
