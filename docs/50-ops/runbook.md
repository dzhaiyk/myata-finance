# Runbook

| Симптом | Причина | Что делать |
|---|---|---|
| Годовой P&L / Cash Flow / «Контроль» показывают неправдоподобную прибыль или пропавшие расходы за поздние месяцы | Supabase (PostgREST) молча отдаёт максимум 1000 строк на запрос | Все объёмные выборки читаются через `fetchAll` (`src/lib/fetchAll.js`) с `.order('id')`. Новую выборку без `fetchAll` не добавлять, если таблица может превысить 1000 строк |
| `npm install` падает с ошибкой сертификата | корпоративный TLS-перехват на машине владельца | новые зависимости не добавляем; PDF и парсеры написаны без библиотек. Если зависимость неизбежна — согласовать с владельцем |
| SQL через MCP с `DELETE` внутри составного запроса отклоняется | классификатор auto-режима блокирует DELETE в многооператорных запросах | выполнять `DELETE` отдельным запросом |
| Выписка сохранена, но на «Контроле» карточка «Выписки к проверке» красная | у файла не сошлись остаток начала + обороты = остаток конца; строки помечены `review_note` | сверить с банком, перезагрузить полный файл; после проверки снять пометку кликом по ⚠ на странице «Импорт выписки» |
| Кнопка «Заполнить из iiko» → «iiko не настроен» | переменные в Netlify не заданы или сайт не пересобран | задать переменные (`docs/50-ops/setup.md`), сделать повторный деплой |
| «Failed to fetch dynamically imported module: .../assets/*.js» | вкладка открыта до пересборки: имя файла изменилось, а SPA-редирект отдаёт на несуществующий файл `index.html` со статусом 200 — браузер получает HTML вместо модуля | с 05.09.2026 чинится само: страница перезагружается, черновик отчёта смены перед этим сохраняется (`src/lib/staleReload.js`). Если ошибка всё-таки показана — значит перезагрузка уже была в последние 30 секунд и дело не в устаревшей вкладке: смотреть, отдаётся ли файл (`curl -I` — тип должен быть `application/javascript`, не `text/html`) |
| «Неверный ключ доступа к прокси» на кнопке iiko | `VITE_IIKO_PROXY_KEY` не совпал с `IIKO_PROXY_KEY` или не попал в сборку | задать обе переменные одним значением, `VITE_`-переменной нужен scope Builds, пересобрать |
| «Авторизация iiko не прошла» | неверные адрес, логин, пароль/SHA1 | проверить `IIKO_SERVER_URL` (без `/resto`), логин пользователя с правами API |
| «Смены сданы» показывает пропуски в дни, когда заведение не работало | дни закрытия не внесены | добавить период в `settings.closures` (`[{from, to, reason}]`) |
| «Необъяснённый остаток» у учредителей уходит в большой минус | не задан остаток наличных на 1 января | `settings.owner_cash_opening` → `{ "<год>": сумма }` |
| Повторная загрузка той же выписки создаёт дубли | операции банка «в обработке» изменили дату или сумму, хеш не совпал | открытый вопрос домена bank (проверить на реальном файле Kaspi) |
| Пароли пользователей видны в базе, RLS открыт | известное ограничение архитектуры | закрывается при переезде на VPS (`docs/20-architecture/security.md`) |
