# Кто принимает решения

| Область | Кто решает | Как фиксируется |
|---|---|---|
| Бизнес-правила (расчёты, статусы, права, что считать доходом/расходом) | **Жайык** — владелец продукта, единственный, кто подтверждает | правило BR-* со статусом CONFIRMED, дата, «источник: интервью» |
| Факты о прошлом (что было в 2022–2025, кто кому платил) | Жайык | `docs/30-decisions/` (если меняет учёт) или примечание к BR |
| Технические решения: библиотеки, схема таблиц, именование, паттерны | инженер (Claude) | значимые — ADR через `/adr`; мелкие — ASSUMED в TASK-файле |
| Секреты и доступы (ключи API, пароли банков, Netlify) | Жайык вводит сам | в документах только имена переменных |
| Доступ менеджеров к приложениям банков | Жайык | решение 04.09.2026: менеджеры могут создавать платежи, подтверждает только учредитель |

Учредители заведения: Жайык, Абу, Әділет (по 1/3; Әділет выкупил долю Алмаса 15.09.2025). В продукте решения принимает только Жайык.

Ответы владельца принимаются в коротком формате («1A, 2C, 3 — по умолчанию»); «не знаю» = статус OPEN.
