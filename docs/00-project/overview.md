# Myata Finance

## Что это
Веб-приложение финансового учёта заведения «Мята | Platinum 4YOU» (Алматы, Казахстан): отчёты смен, импорт банковских выписок, P&L, Cash Flow, зарплаты, счета и остатки наличных, контроль замкнутого контура денег. Сейчас — внутренний инструмент одного заведения; цель владельца — довести его на своём заведении и продавать как SaaS другим заведениям (CONFIRMED · 2026-09-04 · Жайык).

## Для кого
| Пользователь | Что делает в системе |
|---|---|
| Учредитель (владелец продукта) | смотрит P&L, Cash Flow, «Контроль», ставит категории выпискам, принимает решения |
| Управляющий | табель, зарплаты, персонал, поставщики |
| Менеджер смены | заполняет отчёт смены, загружает выписки банков (с сентября 2026) |
| Бухгалтер | категоризация выписок, ФОТ, сверки |
| Админ | пользователи, роли, настройки |

Роли и права — `docs/10-business/access/permissions.md`; кто что решает — `stakeholders.md`.

## Главные процессы
1. **Смена** — менеджер закрывает день: выручка по отделам и типам оплат (вручную или из iiko), расходы из кассы, пересчёт кассы; при расхождении — сигнал в Telegram.
2. **Банк** — выписки Kaspi (Excel) и Halyk (PDF) загружаются ежедневно, строки категоризируются правилами и вручную.
3. **Отчётность** — P&L (по периодам начисления) и Cash Flow (по датам платежей) собираются из смен, банка и ручных правок; история 2022–2025 импортирована из Excel.
4. **Зарплаты** — ведомости по половинам месяца, авансы из смен, техперсонал ежедневно из кассы.
5. **Контроль** — ежедневные сверки: отделы ↔ оплаты, терминалы ↔ зачисления, касса, ФОТ, наличные у учредителей, остатки счетов.

Схема источников данных: `docs/20-architecture/data-model.md`.

## Границы
- Одно юридическое лицо в интерфейсе, но два банковских контура (ТОО и ИП) — счета различаются, отчётность общая.
- Нет складского учёта, нет меню и себестоимости блюд — только деньги.
- Бэкенда нет: вся логика в браузере, Supabase как база; серверная часть только для iiko (Netlify Function).
- Планируется переезд на VPS (self-hosted Supabase) — см. `docs/30-decisions/_index.md`.

## Внешние системы
Supabase, Telegram Bot API, iiko (iikoServer API через прокси), банки Kaspi и Halyk (файлы выписок, без API) — подробно в `docs/20-architecture/integrations.md`.
