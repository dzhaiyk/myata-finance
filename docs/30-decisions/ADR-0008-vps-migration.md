# ADR-0008 · Переезд на VPS (self-hosted Supabase)

## Контекст
Облачный Supabase ограничивает (лимит строк, открытый RLS, секреты в бандле); для SaaS-версии нужен серверный слой и мультиарендность.

## Варианты
1. Остаться на облаке и наращивать Edge Functions.
2. Self-hosted Supabase на VPS + постепенно серверная логика.
3. Полностью свой бэкенд.

## Решение
Владелец (август 2026) выбрал вариант 2. Детали не проектировались.

## Последствия
- При переезде: `db-max-rows`, миграции 019+ вручную, хеширование паролей, RLS по ролям, Telegram-токен на сервер.
- Мультиарендность для SaaS — отдельное решение (открытый вопрос в `docs/10-business/_domains.md`).
