# ADR-0006 · PDF-выписки Halyk без внешних библиотек

## Контекст
Halyk отдаёт выписку только PDF. На машине владельца `npm install` блокируется TLS-перехватом, добавить pdf.js нельзя.

## Варианты
1. pdf.js / pdf-parse — плюсы: полнота; минусы: невозможно установить.
2. Серверный разбор (Netlify Function с библиотекой) — та же проблема с установкой плюс отправка выписки наружу.
3. Свой минимальный парсер под формат Halyk.

## Решение
Вариант 3: `src/lib/pdfText.js` (объекты, потоки, FlateDecode через `DecompressionStream`, простые шрифты и Type0 с ToUnicode) + `src/lib/halykStatement.js` (таблица по координатам, сверка оборотов и остатков). Разбор в браузере, файл никуда не уходит.

## Последствия
- Поддерживаются только PDF, похожие на выписки Halyk; другой генератор PDF может потребовать доработки парсера.
- Тесты собирают синтетический PDF (`halykStatement.test.js`).
