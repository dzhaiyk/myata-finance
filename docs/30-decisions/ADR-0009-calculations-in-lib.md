# ADR-0009 · Расчёты как чистые функции в src/lib с общим кодом для всех экранов

## Контекст
Дашборд считал P&L своей копией и расходился со страницей P&L; аналитика до сих пор считает food cost и ФОТ отдельно.

## Варианты
1. Расчёт внутри страниц (как было) — быстро, но расходится.
2. Общие чистые функции в `src/lib` с тестами `node:test` — один источник, тестируемо без браузера.

## Решение
Вариант 2: `pnlCompute.js` (P&L и дашборд), `reconcile.js` (все сверки), `bankImport.js` (импорт), `dates.js` (операционный день). Страница только вызывает.

## Последствия
- Новое правило BR реализуется в `src/lib` и получает тест с id правила.
- Долг: `AnalyticsPage.jsx` перевести на `pnlCompute` (открытый вопрос домена reporting).
