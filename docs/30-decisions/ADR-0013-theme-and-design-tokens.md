# ADR-0013 · Палитра на переменных, две темы, системный шрифт

## Контекст
Владелец 06.09.2026: шрифты мелкие, нужна светлая тема с выбором пользователя,
приложение выглядит «как стандартный ИИ-продукт».

Цвета были записаны прямо в классах: `text-slate-500` встречался 211 раз,
`text-slate-400` — 111, всего больше шестисот мест в двадцати шести файлах.
Переписать их под вторую тему вручную нереально и означало бы вечное
расхождение: часть экранов осталась бы тёмной.

Кегль: 225 мест по 12 пикселей, 76 мест по 9–11. Отсюда и жалобы.

## Решение
1. **Цвет — через переменные CSS.** Классы Tailwind (`bg-slate-850`) читают
   `rgb(var(--c-slate-850))`. Набор значений меняется на `<html>`, поэтому тема
   переключается целиком и ни один экран не может «отстать».
2. **Светлая нейтраль задана вручную, а не переворотом тёмной.** Карточка
   белая, страница светло-серая: иначе слои сливаются. Акценты на светлых
   оттенках затемняются — зелёный 400 на белом читается плохо.
3. **Тема хранится за пользователем.** Локально — чтобы применялась мгновенно
   и без сети; в `app_users.theme` — чтобы уезжала с человеком на другое
   устройство. Планшет в зале общий, выбор личный. Нет выбора — идём за
   системной настройкой.
4. **Шкала кеглей задана вместе с интерлиньяжем и трекингом.** Мелкий текст
   набирается свободнее, крупный — плотнее. Размеры в `rem`, поэтому системная
   настройка размера текста работает.
5. **Шрифт интерфейса — системный.** На iPhone и iPad это SF Pro: выглядит
   родным и не ждёт загрузки на медленной сети. Из сети остаётся один шрифт
   заголовков вместо трёх семейств.

## Последствия
- Новый экран не нужно «поддерживать» отдельно для светлой темы: он получает её
  из палитры. Но собственные цвета (`#hex`, `rgba(...)`) в компонентах теперь
  запрещены — они не переключатся.
- Тесты цвета не проверяют: это стили. Проверяется поведение выбора темы
  (`theme.test.js`).

## Альтернативы
- **Класс `dark:` у каждого элемента** — тысяча правок и гарантированные
  пропуски.
- **Отдельная тема только для новых экранов** — половина приложения светлая,
  половина тёмная.
