# ADR-0004 · Категоризация выписок: правила в базе, затем правила в коде, первое совпадение

## Контекст
Формулировки в выписках Kaspi меняются; часть правил должен править владелец без деплоя, часть требует регулярных выражений и направления операции.

## Варианты
1. Только правила в коде — плюсы: тесты, регулярки; минусы: каждое новое слово — коммит.
2. Только правила в базе — плюсы: правит владелец; минусы: нет регулярок и направления, нет тестов.
3. Оба слоя: база первой, код вторым, внутри слоя — первое совпадение.

## Решение
Вариант 3 (`src/lib/bankImport.js`, `src/lib/categorize.js`). Правило базы с действием «скрыть» выбрасывает строку. Уверенность: правило базы — `auto`, код по назначению — `high`, по получателю — `medium`, иначе `uncategorized/low`.

## Последствия
- Порядок правил в `KEYWORD_RULES` — часть логики; приоритетный блок (взнос наличных, комиссия за снятие, снятие, эквайринг) стоит первым.
- Канон кодов категорий — миграция 008, контракт проверяется тестом `category-contract.test.js`.
