# ADR-0005 · iiko через Netlify Function

## Контекст
Нужна выручка из iiko в отчёте смены, но всё, что попадает в бандл, видно любому пользователю сайта; у iikoServer каждая авторизация занимает слот лицензии.

## Варианты
1. Вызывать iiko из браузера с ключом в `VITE_*` — ключ утекает.
2. Netlify Function-прокси с белым списком действий и `x-proxy-key`.
3. Ждать VPS и делать полноценный бэкенд.

## Решение
Вариант 2 (`netlify/functions/iiko.js`): режим iikoServer (auth по SHA1 → вызов → logout) или iikoCloud (токен кешируется 55 минут); действия только из белого списка; env-переменные — `docs/50-ops/setup.md`.

## Последствия
- `VITE_IIKO_PROXY_KEY` всё же виден в исходниках — защита от случайного, не от целенаправленного доступа; закрыть можно на VPS.
- Кнопка «Заполнить из iiko» заполняет только выручку; касса, терминалы и изъятия — вручную (иначе нечего сверять).
