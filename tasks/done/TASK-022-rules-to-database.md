в коде оно требовало ещё и получателя-арендодателя (решение 04.09.2026), а в
базу уехало только по назначению платежа. Первая контрольная сумма этого не
поймала, потому что не включала дополнительные условия — считал по неполному
ключу. Нашли тесты. По данным: при следующем импорте одна операция на 50 307 ₸
(доход от субаренды зарядных станций) ушла бы из доходов в аренду помещения.
Условие добавлено, сумма пересчитана по полному ключу.
